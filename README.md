# fantasy-basketball-9cat-projector
A personal, non-commercial Microsoft Excel application developed for analyzing Yahoo Fantasy Basketball head-to-head matchups.

The application uses Python and basketball statistics APIs to calculate player projections, track weekly performance, and forecast results across nine fantasy basketball categories.

Planned Yahoo Fantasy Sports API integration:

Retrieve my fantasy basketball league information

Automatically synchronize my roster and my opponent's roster

Retrieve weekly matchups and scoring data

Identify active and benched players

Display fantasy matchup projections in Microsoft Excel

Intended users: One user, for personal fantasy basketball analysis.

Platform: Microsoft Excel and Python on Windows.

Access: Locally run application, not publicly distributed or monetized.

Yahoo API permissions requested: Read-only.
